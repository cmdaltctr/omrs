# Label guideline: Part 2 correctness

Experiment 35, task 16.8 (pre-registration section 11.3, P8). Do not edit this file by hand. `guidelines35.py` builds it from the label page constants in `labelpage35.py`. To change it, change the constants and run:

    uv run --no-sync python experiments/35-full-rag-benchmark-2026-11-01/guidelines35.py

This guideline uses the choices, rules and worked examples of the correctness set, because pre-registration section 18 applies the section 11.2 correctness gate rule to C2.

## What you see

1. Question: on the left.
2. Reference answer: on the left.
3. Answer: on the right, beside the choices.

## Choices

Pick one choice for each item.

### Correct (`correct`)

Rule: The answer gives the key facts of the reference answer and contradicts none.

Worked example (label Correct): Reference: "Paris." Answer: "The capital is Paris."

### Not correct (`not_correct`)

Rule: Any other case.

Worked example (label Not correct): Reference: "Paris, with 2.1 million people." Answer: "Paris." (a key fact is missing)

### Can't tell (`cant_tell`)

Rule: Use this rarely. Choose it only when you cannot read what the answer claims.

Worked example (label Can't tell): The answer stops in the middle of a sentence.

The worked examples are made up for this guideline. None comes from a dataset, so none is in a sample.

## Registered rules

Each rule below is copied word for word from the file named after it.

- C2 needs its own Part 2 correctness gate (the section 11.2 rule, labels from both systems); a failed gate leaves C2 in the family as not testable. (`preregistration.md`)
- L2 is the primary Part 2 labeller and labels every Part 2 item (O4, section 11.3); system identity is hidden; both systems' answers are shuffled into one list (seed 20261132). (`preregistration.md`)
- The gate passes on a dataset when kappa is at least 0.60 with a lower 95% bound of at least 0.40, computed with "can't tell" items scored both as correct and as not correct (both must pass). (`preregistration.md`)
- Labellers never see scores, verdicts, setup names or chunk sizes. (`preregistration.md`)
- Disagreement rule: L1 and L2 discuss; if they cannot agree, the item is "can't tell" and counted. (`preregistration.md`)
- A training round on practice items comes first and is not evidence. (`preregistration.md`)
