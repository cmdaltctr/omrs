# Label guideline: Faithfulness

Experiment 35, task 16.8 (pre-registration section 11.3, P8). Do not edit this file by hand. `guidelines35.py` builds it from the label page constants in `labelpage35.py`. To change it, change the constants and run:

    uv run --no-sync python experiments/35-full-rag-benchmark-2026-11-01/guidelines35.py

## What you see

1. Question: on the left.
2. Passages cited: on the left, one panel per cited passage.
3. Sentence to label: on the right, beside the choices.

## Choices

Pick one choice for each item.

### Supported (`supported`)

Rule: Every part of the sentence is stated in the passages or follows directly from them.

Worked example (label Supported): Passage: "Weight: 2 kg." Sentence: "The device weighs 2 kg."

### Not supported (`not_supported`)

Rule: Any part is missing from the passages or is contradicted by them.

Worked example (label Not supported): Passage: "Weight: 2 kg." Sentence: "The device weighs 2 kg and is waterproof."

### Can't tell (`cant_tell`)

Rule: Use this rarely. Judge the sentence as written: do not fill in a missing subject from the question. If the meaning is unclear, choose this.

Worked example (label Can't tell): Sentence: "It was approved in May." (no subject, so the meaning is unclear)

The worked examples are made up for this guideline. None comes from a dataset, so none is in a sample.

## Registered rules

Each rule below is copied word for word from the file named after it.

- Faithfulness follows the LLM-AggreFact task definition (MiniCheck): a claim is supported if and only if the cited passages support it, judged as the checker sees it, on meaning not grammar. (`preregistration.md`)
- Judge the claim exactly as the checkers see it. Do not fill in a missing subject or a pronoun from the answer or the question. If the claim cannot be checked as written, label it "Can't tell". (`protocol.md`)
- Judge the meaning, not the grammar. If a garbled sentence still has one clear meaning and the passages support it, label it "Supported". Label "Can't tell" only when the meaning itself is unclear. (`protocol.md`)
- "Can't tell" counts as not supported (the binary benchmark scale); kappa is also reported with "can't tell" items left out. (`preregistration.md`)
- Labellers never see scores, verdicts, setup names or chunk sizes. (`preregistration.md`)
- Cited passage length can still hint at chunk size; the report says so. (`preregistration.md`)
- Disagreement rule: L1 and L2 discuss; if they cannot agree, the item is "can't tell" and counted. (`preregistration.md`)
- A training round on practice items comes first and is not evidence. (`preregistration.md`)
