# Stages of the Experiment 35 test pod session (task 9.2; gaps G6, G15 to G17, G24).
# pod_test_session.sh runs them in order (the line format is in its header); the Mac
# starts it through launch35.sh. Plan: DATA/omrs/handoffs/2026-11-23-exp35-test-pod-
# session-plan.md, section 7. Every runner line passes --prefreeze and writes under
# $OUT_DIR (default $WORK/exp35-test/out), never into the main output folder.
#
# POD (create_pod35.py): one RTX 4090, secure cloud, the pinned image digest (task 9.1),
# container disk 120 GB, and a VOLUME DISK of 40 GB (mounts.persistent), the spare copy.
# All work is in $WORK (/root/exp35-work) on the container disk, which is local on every
# host. The chain packs each finished stage into $WORK/stage-out and the Mac pulls it
# (gap G10). The volume keeps a spare copy of those tarballs for a resume.
#
# What the setup stage leaves in place (the contract with pod_setup35.sh):
#   the repository at $COMMIT, synced; llama.cpp b11941 (CUDA); every GGUF file of the
#   plan.json runtime block in $SWEEP_GGUF_DIR (container disk), SHA-256 checked; the
#   Experiment 35 data in the default data folder; prepared passages in
#   $WORK/passages; the Ragas environment $WORK/ragas-venv; the reference
#   environment /root/exp35-ref-venv (the project with the torch extra, used through
#   UV_PROJECT_ENVIRONMENT); the inputs, with classify-examples.json, in $WORK/inputs.
#
# Folders under $OUT_DIR: s smoke folder (answers, judges, Ragas, claim kinds, join);
# t timing slices; rb, chk and rbs rebuild check (G16); tput reranker throughput; vram
# 8B embedder plus 8B reranker; r FreshStack recheck; rerank; idle and idle-held; sl
# Legal smoke folder; gate; fsfull; router-logs. The recheck, throughput and VRAM runs
# read the indexes of s or t with --index-from and write their own folder, so the smoke
# join of s sees only the smoke setups (G17).
#
# Calibration (task 9.2 step 3): each answer, judge, Ragas and claim-kind line holds
# one runner call with its start concurrency, so the chain halves it and resumes once
# on a rate-limit stop (exit 5), and resumes once on exit 4 or 6 (G15).
#
# Legal RAG Bench lines start with a data check and exit 77 (skipped) when its prepared
# passages are not on the pod. Legal has its own smoke folder (sl) and one setup, so the
# core join, the gate sample and the core rebuild checks never depend on it.
#
# Task 8.7: the gate classify is the last stage (owner decision, 2026-11-23). The owner
# labels the sample blind: keep gate/sample-kinds.jsonl unopened until the labels are
# saved. The log shows only the count and the classifier version.
