How to read the re-run column:

- **GGUF**: the public GGUF file a llama.cpp re-run would use. "check" means the file was not confirmed. A Hugging Face repository named here was confirmed to exist on 27 October 2026; that the file matches the original weights was not checked unless the row says so.
- **Not llama.cpp**: ONNX rerankers, OCR engines and Magika are outside the llama.cpp rule (design.md, Non-goals). The existing runtime-manifest requirement covers them.
- **Data**: `DATA/omrs/...` paths are copies listed in `DATA/omrs/DATA_LOCATIONS.md` and seen in the folder listing. "Not in DATA/omrs" means no copy there; the inputs are tracked files in the experiment folder or a public dataset that a script in the folder prepares.
- **Hosted**: hosted models used as arms or references.
