## 3. The router page rule

Group 3 follows `docs/guides/reading-parts.md` (Add a page rule) and the group-1 discipline of `local-ocr-backends`. Before any production edit, run `tests/unit/test_page_routing_golden.py` and `tests/unit/test_reading_parts_digest_pins.py` and record that they pass. With no router selected they must stay byte-identical to the end of the change. A moved pin is a stop: report it and wait.

- [ ] 3.1 Tests first: the hook amendment (design D4). `RuleOutcome.add`, `RuleContext.claimed` and `RuleContext.judge` default to empty or `None`. Only a rule whose registration declares `adds_pages` may return a non-empty `add`; any other rule returns a bad outcome (a built-in rule fails the file; a discovered rule is skipped with one warning and switched off). A valid added page is in the scan, has text, is unflagged and is not claimed. Added pages join the direct set once (a page named by two rules, or added and sent direct, appears once in the page-listed request). A later rule's `drop` removes an added page; the final direct set is the union minus every dropped page; `claimed` holds the earlier drops, direct and added pages. `PageRuleDescriptor` and `register()` carry `adds_pages`, pinned like the other four facts. Confirm the path of the judge from compose to the rule in the code (`core/ingestion/backends/local.py`, `integrations/pdf/factory.py`, `OcrRoutedPdfInspector`, `run_rules`) and write the test for it. Verify: `uv run pytest tests/unit -k "page_rule or reading_parts" -q` passes; the golden snapshots and digest pins pass unchanged; a mutation that lets a rule without `adds_pages` add pages fails a test; a mutation that skips the minus-dropped step on the final direct set fails a test.
- [ ] 3.2 Tests first, in the page unit: an added page goes to the one page-listed request and not to the local tier; with no engine the router's degrade hook sends it to the local tier with one warning; with no tier it keeps native text and counts unresolved; `pages_needing_ocr` stays the scan count; `ocr_required` is true when a page is added; the five counts sum to the page count; 1 rejected page of a 1,000-page fixture sends exactly 1 page to OCR; a protocol 1.0 worker degrades added pages to unresolved with a warning.
